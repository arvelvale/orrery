ORRERY · COCKPIT

What it does

Eight tools keep sessions in eight different places. Orrery puts them on one board.

01 · SESSIONS

Every session, accounted for.

Title, project, model, tokens and disk size for every session from every tool, searchable in one list. See which tool and which project the gigabytes went to.

  • Tokens counted once per API call: input · cache write · cache read · output
  • Index kept on disk: 188 sessions open in 0.12 s instead of 5.5 s

02 · TRANSFER

Move a conversation to another tool.

Started in Claude Code and want to carry on in Codex or OpenCode? Orrery copies the conversation into the other tool's own history, through that tool's own importer where it has one, and you resume it there. The original stays where it was.

  • Claude Code ⇄ Codex ⇄ OpenCode, all six directions
  • Images the target can't hold are saved as files, never silently dropped

03 · CLEAN UP

Free the disk, safely.

Sort by size, pick what you no longer need, and send it to the Recycle Bin. Each tool's own index is cleaned too, so nothing is left pointing at a missing file.

  • Sessions written in the last 10 minutes, or still open in Claude Code or Antigravity, are skipped
  • Index files are backed up to ~/.orrery/backups before any change

04 · PROXY

One model proxy for every agent.

Point your tools at a single local endpoint and switch models in one place. OpenAI and Anthropic request shapes, with streaming passed straight through.

  • Listens on 127.0.0.1:8787 only, never on your network
  • Start and stop it from the app

Supported tools

What Orrery can do with each tool.

Tool Sessions & tokens Resume in terminal Delete Transfer

Read-only tools keep their sessions in their own database or app, which Orrery reads but does not change. Other OpenCode-style tools can be registered in ~/.orrery/harnesses.json.

Local first

Your sessions stay on your machine.

Reads what's already there

Orrery doesn't wrap or replace your agents. It reads the files they already write, and keeps working when you switch tools.

No account, no telemetry

There is nothing to sign in to and nothing reported home. The only network traffic is the model proxy, when you turn it on.

Open source

MIT licensed. Every line that touches your sessions is on GitHub.
